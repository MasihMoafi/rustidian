# Rustidian development priorities

1. Preserve note bytes, Undo/Redo, external-change protection and recovery.
2. Fix reproducible editing, navigation and layout defects before adding features.
3. Keep interface controls consistent and verify actual rendered behavior.
4. Measure equivalent user workflows before making comparative speed claims.
5. Expand Obsidian-style feature coverage in small, independently verified increments.

The [coverage ledger](PARITY.md) records current capabilities and gaps. Plugin compatibility, browser-rendered HTML, PDF and an agent tab require additional implementation; they are not promises of the current release.
