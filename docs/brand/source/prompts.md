# Rustidian logo prompts

Use Elpis's built-in image tool to edit the approved artwork. The [artwork guide](../README.md) owns the output paths and the [palette guide](../themes/README.md) owns the colours.

1. Edit the installed pink Rustidian icon: remove the yellow-orange light in the middle, its bloom and the warm emissive highlights around the opening. Replace them with dark raspberry and magenta shading continuous with the surrounding surfaces. Preserve the silhouette, proportions, orientation, folds, negative space, subtle texture and soft external studio lighting. Keep the hollow readable through darker shading. No redesign, text or backdrop; use a transparent square canvas.
2. For each other palette, use the approved result as the geometry reference and the previous themed icon only as a colour reference. Change the colours while preserving the silhouette, folds, shading, dark hollow, texture and composition. Keep every interior non-emissive, with no central hotspot or glow. Teal uses petrol shadows and muted turquoise highlights; Love Space uses deep burgundy and ruby red; Elpis Gold uses dark bronze shadows and satin amber-gold surfaces.

Export the generated images as transparent 512 px PNGs without further artwork changes.
