# Rustidian artwork

The logo is a smooth stone split open, with a shaded hollow and no inner light. Masih selected the pink Signature version. The artwork and its colour variants were edited with the image tool built into Elpis, using the instructions in [source/prompts.md](source/prompts.md).

- `store-icon.png`: the main pink Signature logo, a transparent 512 px PNG. Snap, AppImage, the .deb and the portable archive use it. `snap/gui/rustidian.png` is the identical packaging copy.
- `rustidian.png` and `themes/*.png`: the transparent 512 px palette variants listed in [themes/README.md](themes/README.md). The app shows the one that matches the chosen palette. The main logo is identical to `themes/signature.png`.
