# Rustidian palettes

Colour variants of the approved Rustidian stone logo, generated from the same pink reference with a dark hollow and no inner light. All four are transparent PNGs, shown together in the [project README](../../../README.md). The main logo is Signature pink; the app keeps its existing palette selection.

- Teal: petrol shadows and turquoise surfaces, accent `#65b7b6`.
- Love Space: Elpis burgundy `#8B1017`, ruby `#ec575e`.
- Elpis Gold: Elpis amber `#f2a93b`.
- Signature: the approved main logo, with magenta-pink surfaces and burgundy shadows. Its native UI uses [Masih’s website](https://masihmoafi.com/) accents: magenta `#cf1259`, coral `#fa766b`, gold `#ffd873`.

Native palettes also provide light backgrounds and darker link colors for legibility. They do not load Obsidian CSS themes or plugins.
