# Rustidian palettes

Color variants of the Rustidian stone logo (recolours of one traced vector). Teal is the main palette and appears beside all three variants.

- Teal: the main stone, accent `#65b7b6`.
- Love Space: Elpis burgundy `#8B1017`, ruby `#ec575e`.
- Elpis Gold: Elpis amber `#f2a93b`.
- Signature: [Masih’s website](https://masihmoafi.com/) magenta `#cf1259`, coral `#fa766b`, gold `#ffd873`.

Native palettes also provide light backgrounds and darker link colors for legibility. They do not load Obsidian CSS themes or plugins.
