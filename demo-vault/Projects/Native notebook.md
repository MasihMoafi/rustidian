# Native notebook

An Obsidian-like notebook with a Rust interface, Rust editor, and Rust Markdown renderer.

## First milestone

- [x] File explorer and tabs
- [x] Markdown editing and reading
- [x] Search and quick switcher
- [x] Wiki links and backlinks
- [x] Atomic saves with external-change detection

## Measure what matters

Startup, opening notes, typing, search, and memory all need measurements. A Rust implementation is a starting point; it does not establish a speedup on its own.
