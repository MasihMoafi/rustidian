# Connected thinking

A note does not have to stand alone.

Write `[[Home]]` to link to another note. A path such as `[[Projects/Native notebook]]` resolves a specific note. Use `[[Home|back home]]` when the label should read differently.

## Follow a thread

Links in reading view open native tabs. Backlinks on the right reveal notes that point here.

If two notes share a name, use a path so the destination is clear.

## Keep it portable

The vault stays a folder of ordinary `.md` files. Your notebook can still be opened with another editor.
