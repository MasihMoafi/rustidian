# First steps

## Open and write

1. Press **Ctrl+E** to switch from reading to editing.
2. Type a thought, then press **Ctrl+S** to save it.
3. Press **Ctrl+E** again to see the Markdown preview.

Use the split-view button above the note to keep source and preview side by side.

## Move around

| Shortcut | Action |
| --- | --- |
| Ctrl+O | Open a note |
| Ctrl+N | Create a note |
| Ctrl+S | Save changes |
| Ctrl+E | Switch reading and editing |
| Ctrl+W | Close the current tab |
| Ctrl+P | Open commands |

## Keep your work

If a file changes outside the app, saving will stop and tell you. Your edits remain open. Use **Save a copy** in the command palette to preserve both versions.
